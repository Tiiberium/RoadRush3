# Road Rash 3 (Rus) — нативная сборка для Windows

Статическая рекомпиляция ROM `Road Rash 3 (R).bin` (Sega Mega Drive) в нативный
исполняемый файл Windows. Эмулятора нет: машинный код 68000 и звукового Z80
переведён в C# заранее и скомпилирован в `bin\RR3.exe`.

## Запуск

`bin\RR3.exe` или ярлык в корневом разделе (рядом должен лежать `rr3.bin` — он используется как ресурс данных:
графика, звук и уровни читаются из него).

### Управление (по умолчанию, меняется в меню Esc → «Управление»)

| Клавиша | Действие |
|---|---|
| W | газ (также «выбор» в меню игры) |
| A | тормоз |
| S / ← | поворот налево |
| D / → | поворот направо |
| Q | удар |
| E | удар назад (ногой) |
| ↑ / ↓ | вверх / вниз в меню игры |
| Enter / Пробел | Старт / пауза игры |
| Esc | меню паузы с настройками |
| F11, Alt+Enter, двойной клик | окно ↔ полный экран |
| F12 | скриншот в итоговом разрешении (`bin\screenshots`) |

Геймпад XInput (Xbox): A/RT — газ, X/LT — тормоз, B/RB — удар, Y/LB — удар
назад, стик/крестовина — руль, Start — старт, Back — меню паузы.

### Меню паузы (Esc)

- **Управление** — по две клавиши на действие; Enter/клик — назначить,
  Delete/ПКМ — очистить, сброс по умолчанию, вкл/выкл геймпада.
- **Графика** — окно/полный экран; разрешение 1280×720…3840×2160 (в окне —
  размер окна, в полном экране — разрешение рендера); улучшение графики:
  пиксели, чёткое сглаживание, xBR HD, xBR HD мягкий; сглаживание дизеринга;
  пропорции 4:3 / растянуть / целочисленно; размытый фон по краям; ЭЛТ-эффект;
  VSync; счётчик FPS.
- **Звук** — громкость, вкл/выкл.
- Начать игру заново, выйти.

Настройки сохраняются в `bin\settings.ini`. Вывод — OpenGL 2.0 (шейдеры);
если он недоступен, используется простой GDI-вывод.

## Как это устроено

- `tools/m68kdec.py` — декодер инструкций 68000.
- `tools/analyze.py` — поиск кода: рекурсивный обход от векторов, таблицы
  переходов (`jmp d(An,Xn)`, `lea tbl,An` + `jsr (An)`), указатели на функции
  в данных, код после `rts`/`bra`.
- `tools/gen68k.py`, `tools/build68k.py` — генерация `runtime/Gen68k.cs`:
  ~11 700 блоков, каждый блок 68000 → метод C#, с удалением неиспользуемых
  вычислений флагов.
- `tools/z80gen.py`, `tools/buildz80.py` — то же для звукового драйвера Z80
  (ROM 0x3B568, 0x1B27 байт) → `runtime/GenZ80.cs`, включая самомодифицирующийся
  вычисляемый `jr` по адресу 0x0581, `jp` по 0x1623 (цель переписывается при запуске
  сэмплов ЦАП) и операнд `ld a,($04xx)` по 0x1636 (таблица сэмплов). Сборщик
  предупреждает о любых новых записях драйвера в собственный код.
- `runtime/` — платформенный слой: VDP (плоскости, окно, спрайты,
  shadow/highlight, DMA, HInt/VInt), YM2612 + PSG, waveOut-аудио, контроллер.
- `runtime/GlRenderer.cs` — OpenGL-вывод: шейдер xBR-lv2, sharp-bilinear,
  размытый фон, сканлайны, рендер в текстуру выбранного разрешения.
- `runtime/Menu.cs`, `Settings.cs`, `Input.cs`, `Program.cs` — меню паузы,
  настройки, клавиатура/XInput, окно и синхронизация кадров (VSync или звук).

## Сборка

Нужны Python 3 и .NET Framework 4 (`csc.exe` входит в Windows):

```
build.cmd
```

`seeds.txt` / `seeds_z80.txt` — дополнительные точки входа. Если в редкой
ситуации появится сообщение «Unrecompiled code at XXXXXX», адрес будет записан
в `bin\missing.txt`: добавьте его в `seeds.txt` и пересоберите.

Тест без окна: `bin\RR3_console.exe --frames 3000 --shot 100 --input "1200:S,1208:,2000:B" --wav`.
Фаззинг покрытия: `powershell -File fuzz.ps1`.
